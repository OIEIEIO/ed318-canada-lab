# ed318-canada-lab

## Mission
A neutral, auditable engineering laboratory for learning, validating, implementing, and comparing EUROCAE ED-318 geographical-zone data and future Canadian RPAS geo-awareness profiles.

## Principles
- Preserve official datasets unchanged.
- Record provenance for every dataset.
- Separate standards from implementation.
- Separate implementation from national profiles.
- Reproducible validation and testing.
- Evidence-based engineering.

See PROJECT_PHILOSOPHY.md and ROADMAP.md.

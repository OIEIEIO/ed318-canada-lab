## v0.3.0 — 2026-07-29

### Changed

- Reframed the repository as an ED-318 implementation and strategy reference laboratory.
- Replaced the validator-first roadmap with a reference-first development sequence.
- Reorganized country research under `implementations/`.
- Standardized terminology for the standard, reference schemas, reference examples, national implementations, publication strategies, source datasets, and derived samples.
- Updated the Rust placeholder version and message without adding software capability.

### Added

- Ireland national implementation profile based on the supplied real-world dataset.
- Spain national implementation profile based on supplied ENAIRE Aero, Infra, and Urbano datasets.

- Czech publication-system study placeholder.
- Future Canadian implementation-strategy study.
- v0.3.0 semantic audit, modified-file list, and full diff.

### Removed or retired

- The old country-folder structure and premature profile hierarchy.
- Documentation that presented JSON Schema validation as the next immediate software capability.
- The synthetic Canada learning-zone sample from the primary project structure.

### Not added

- No parser.
- No validator.
- No normalizer.
- No implementation auto-detection.
- No operational geo-awareness capability.

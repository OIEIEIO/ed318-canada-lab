# Canada Profiles

Canadian geo-awareness material is separated by authority status:

- `official/` — only requirements, schemas, or profiles published by an authorized Canadian source.
- `proposed/` — documented project or external proposals under evaluation.
- `experimental/` — prototypes, mappings, fixtures, and implementation research.

Nothing in `proposed/` or `experimental/` is Transport Canada or NAV CANADA policy. Moving material between status directories requires a documented evidence review and release audit.

## Status

Publication-system study only. No Czech JSON source file was inspected for v0.3.0.

- many individual LKR geographical-zone products;

## Preliminary lesson

The Czech strategy appears to treat ED-318 as one output of a broader national publishing system. Its lifecycle, tiling, future-effective releases, and integrity metadata are as important to study as its eventual field layout.

## Deferred work

A future release should acquire a manageable tile or representative Czech ED-318 file and inspect:

- top-level structure;
- feature property layout;
- geometry types;
- vertical layers;
- schedules and authority information;
- strict differences from the reference schemas;
- relationship between thematic source products and consolidated ED-318 output.

No field-level Czech claims should be added before that inspection.

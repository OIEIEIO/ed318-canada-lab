# ED-318 in This Repository

## What this repository contains

The repository contains an imported machine-readable schema snapshot and synthetic examples from the associated GitHub material. It does not redistribute the ED-318 standard text.

## Controlled distinction

- **ED-318 standard:** normative publication.
- **Reference schemas:** machine-readable comparison artifacts under `schemas/ed-318/`.
- **Reference examples:** synthetic files under `vendor/ED-318/examples/`.
- **National implementations:** real public datasets studied under `implementations/`.

## Reference-schema observations

The imported schema set includes:

- GeoJSON geometry and LayeredGeoJSON support;
- geographical-zone collection structure;
- zone properties;
- authority information;
- collection metadata;
- time periods;
- common ED-318 data types.

The reference zone-property schema requires `identifier`, `country`, `type`, `variant`, and `zoneAuthority`. It uses the singular property name `reason`. The LayeredGeoJSON schema adds vertical `layer` information to geometry.

## Interpretation rule

A national dataset may carry the same operational concepts without serializing them exactly like the reference schemas. The project documents that difference rather than silently treating one structure as another.

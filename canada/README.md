# Future Canadian Implementation Strategy

## Status

Research questions only. This directory contains no official Transport Canada or NAV CANADA ED-318 profile.

## Central question

If Canada were to publish national UAS geographical zones using ED-318 concepts, which implementation and publishing choices would best fit Canadian authorities, data sources, geography, language requirements, update cycles, and operational needs?

## Lessons to study

### From Ireland

- value of close alignment with the reference property model;
- simplicity of a consolidated national publication.

### From Spain

- thematic separation of aviation, infrastructure, and urban/public-safety information;
- consequences of nested and flattened publication variants;
- handling of authority contact details and operational messages.

### From the Czech Republic

- national source-product organization;
- complete and tiled distributions;
- effective dates and future releases;
- checksums and lifecycle transparency.

## Canadian questions

- Which organization would publish or aggregate the national product?
- Would authoritative source layers remain distributed across federal, provincial, municipal, and infrastructure authorities?
- Would Canada publish one file, thematic products, tiles, or all three?
- How would English and French text be represented?
- How would AIRAC and non-AIRAC source updates be reconciled?
- Which vertical reference systems and units would be permitted?
- How would emergency, temporary, and local restrictions be represented?
- What integrity and provenance guarantees would be required?
- How would a Canadian profile remain compatible with international geo-awareness devices?

These questions precede any proposed Canadian data model.
